# Changelog

## 0.1.0 - 2026-10-27
- First package release, extracted from the Robot Race project.
- Kit pieces with sockets, walls, gate and spawn markers (Build Kit, Validate Kit).
- Track Builder window with Place Next and Flip.
- Check Joints: open/bent/stepped joints, gaps, overlaps, walls on the road, foreign floor.
- Bake through a game adapter (`ITrackKitAdapter`); per-project `TrackKitSettings` asset.
